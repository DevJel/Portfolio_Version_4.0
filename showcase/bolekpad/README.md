## Contents
- `index.html`: project showcase entry point.
- `login/index.html`: simulated sign-in page; accepts any valid email and any demo code, then opens the dashboard. It does not authenticate or transmit credentials.
- `dashboard/index.html`: displays the matching original portfolio screen asset from the repository's `assets/` directory.

## Design and screenshots
The dashboard preview reuses the original portfolio Mac-screen HTML asset, preserving its embedded screenshot artwork and existing screen presentation. The login is a clearly labeled demonstration entry screen because a separate approved production login screenshot/source was not supplied in the portfolio assets. It does not claim to reproduce the production authentication flow.

## Production source
Private production repository; this public folder contains showcase-only pages.

## Local use
Open `index.html` in a browser or serve the repository using any static HTTP server. No build command or environment variables are required.

## Security
Do not add production credentials, API keys, private keys, environment files, customer data, employee data, or internal operational records to this public repository. Private production source remains in its original private repository.
